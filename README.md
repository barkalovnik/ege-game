# Интерактивный тренажёр «КЕГЭ: Базовые прототипы 1–27»

Тренажёр создан на базе заданий из папки проекта (самые лёгкие прототипы каждого типа компьютерного ЕГЭ по информатике) в строгом, инженерном стиле без визуального шума и шаблонов.

---

## 🚀 Как запустить

Тренажёр полностью автономен и не требует установки серверов или сборщиков:
1. Откройте файл **[`index.html`](file:///c:/Users/Lecoo/projects/ege/index.html)** в любом современном браузере (Chrome, Edge, Firefox, Safari).
2. Или запустите через проводник двойным щелчком по `index.html`.

## ⚡ Особенности интерфейса

- **Анти-шаблонный дизайн (Taste-Skill)**: спокойная палитра (глубокий технический графит с янтарными акцентами), чёткая типографика на базе JetBrains Mono и системного гротеска, отсутствие «мусорных» градиентов и навязчивых баннеров.
- **Горячие клавиши**:
  - `Enter` — мгновенная проверка введённого ответа.
  - `[` или `←` — предыдущее задание.
  - `]` или `→` — следующее задание.
  - `F` — добавить текущее задание в избранное.
- **Инструменты прямо на рабочем столе**:
  - Полноразмерный зум скриншотов по клику.
  - Встроенный калькулятор степеней двойки, байт и арифметических выражений (поддерживает синтаксис Python: `2**14 / 1024`, `14 & 5`, `165615 / 61`).
  - Личный автосохраняемый черновик к каждому заданию.
- **Сохранение прогресса**: все введённые ответы, отметки избранного, верные/неверные статусы и черновики сохраняются в `localStorage` браузера.
